# 🎨 Vue + Vite DIY Avatar Generator

一个基于 **Vue 3 + Vite** 打造的开源头像生成工具，支持自定义肤色、背景、五官、配饰等元素，可用于
✔ 个人头像  
✔ 社交平台头像  
✔ 项目示例图  
✔ 插画风格角色展示

🚀 即开即用 · 支持本地预览与图片导出

---

## ✨ 功能特性

- 🧩 多种头像样式组合
- 🎨 自定义颜色（肤色 / 头发 / 背景）
- 👓 五官元素随意搭配
- 🧢 支持配饰组件扩展
- 📦 实时预览
- 🖼 一键导出 PNG 图片
- ⚡ 基于 Vite 构建，轻量高性能

---

## 🛠️ 技术栈

- Vue 3
- Vite
- Canvas / SVG 渲染
- JavaScript / TypeScript（可选）
